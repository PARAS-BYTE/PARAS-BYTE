## Engineering Workflow

### How I ship software

```mermaid
flowchart LR
    A[Requirements and<br/>edge cases] --> B[Schema and<br/>API design]
    B --> C[Implementation<br/>React / Next.js / Node]
    C --> D[Validation<br/>Zod and typed contracts]
    D --> E[Automated tests<br/>unit, security, acceptance]
    E --> F[Deploy<br/>Vercel / Render]
    F --> G[Monitor and<br/>iterate]
    G -.-> A

    classDef step fill:#0f172a,stroke:#2563eb,stroke-width:2px,color:#ffffff;
    class A,B,C,D,E,F,G step;
```

### How my agentic pipelines work (AutoClean AI)

```mermaid
flowchart TD
    S([Raw CSV]) --> P[Dataset Profiler<br/>shape, nulls, outliers, types]
    P --> U[Understanding Agent<br/>audit quality]
    U --> R1{Cleaning<br/>required?}
    R1 -- No --> F[Finalizer<br/>audit report]
    R1 -- Yes --> C[Cleaning Agent<br/>generate pandas code]
    C --> X[Execution Engine<br/>run script, write CSV]
    X --> R2{Executed<br/>successfully?}
    R2 -- Error traceback --> C
    R2 -- Success --> V[Validation Auditor<br/>integrity and category-loss checks]
    V --> R3{Verdict}
    R3 -- Fail --> C
    R3 -- Pass or Blocked --> F
    F --> E([Cleaned CSV])

    classDef agent fill:#0f172a,stroke:#38bdf8,stroke-width:2px,color:#ffffff;
    classDef router fill:#312e81,stroke:#a855f7,stroke-width:2px,color:#ffffff;
    classDef io fill:#1e1b4b,stroke:#818cf8,stroke-width:2px,color:#ffffff;
    class P,U,C,X,V,F agent;
    class R1,R2,R3 router;
    class S,E io;
```
